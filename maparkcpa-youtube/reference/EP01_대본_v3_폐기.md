# 0. v2 대본이 왜 안 읽혔는가

첨부해주신 대본과 제 v2를 나란히 놓고 비교했습니다. 지적이 맞습니다. 원인은 네 가지였습니다.

### ① 숫자를 15개나 넣었습니다

v2는 2분 30초 동안 통계를 6개 연속으로 던졌습니다. 15.3%, 43%, 2.6%, 49.7%, 38%, 56.8%. 이러면 시청자는 **하나도 기억하지 못합니다.** 뉴스 브리핑이 되는 이유가 이겁니다.

첨부 대본에는 숫자가 거의 없습니다. 대신 "파트너 1명 + 회계사 20명"처럼 **머릿속에 그림이 그려지는 구조**를 씁니다.

→ **v3에서 숫자를 5개로 줄였습니다.** 대신 각 숫자에 오래 머뭅니다.

### ② 질문이 없었습니다

첨부 대본은 계속 묻습니다. "AI가 회계사의 일을 할 수 있을까?" "그렇다면 전문직의 가치가 없어질까요?" "그러면 누가 살아남을까?" 묻고 답하는 구조 자체가 **같이 고민하는 느낌**의 정체입니다.

v2에는 질문이 마지막 CTA에만 있었습니다. 나머지는 전부 단정문이었고요.

→ **v3는 파트마다 질문으로 열고 답으로 닫습니다.**

### ③ "저는 ~라고 생각합니다"가 없었습니다

첨부 대본에서 이 표현이 아홉 번 나옵니다. 이게 결정적입니다. 같은 내용도 "~입니다"로 쓰면 보도가 되고, "저는 ~라고 봅니다"로 쓰면 **의견 공유**가 됩니다.

v2는 전부 "~습니다"였습니다. 앵커 톤이었던 겁니다.

→ **v3는 파트당 최소 1회 화자의 견해 표지를 넣었습니다.**

### ④ 문장이 길었습니다

첨부 대본은 한 문장이 한 줄입니다. 짧게 끊어서 리듬이 생깁니다.

v2는 정보를 욱여넣은 복문이 많았습니다. 눈으로 읽으면 괜찮은데 **소리로 들으면 따라가기 힘듭니다.**

→ **v3는 한 문장 25자 이내를 기본으로 잡았습니다.**

### 다만 하나는 지켜야 합니다

첨부 대본의 약점은 **숫자가 없다는 것**입니다. 그대로 가면 "회계사의 견해"는 되지만 "확인 가능한 관찰"은 안 됩니다. 블로그 글과 구분이 안 되고, 채널 제작 원칙 4번과도 어긋납니다.

그래서 v3는 **첨부 대본의 말투 + 핵심 숫자 5개**로 잡았습니다. 숫자를 줄인 만큼 남은 숫자는 더 세게 씁니다.

# 1. 남긴 숫자 5개

| 숫자 | 쓰이는 곳 | 왜 남겼나 |
|---|---|---|
| **2.6%** | PART 1 | 신입 전용 공고 비중. 직관적으로 충격적 |
| **-28.5만 / +23만** | PART 1 | 청년 vs 50대. 대비 구조가 강함 |
| **862 / 1,200** | PART 2 | 이미 벌어진 사건 |
| **375→268 / 1,750→2,095** | PART 2 | ★ 이 영상의 유일한 증명 |
| **1명 + 20명 → 1명 + 5명** | PART 5 | 숫자가 아니라 그림 |

버린 것: 500대 기업 15.3%, 캐치 43%, 은행 38%, 증권 56.8%, 응시자 14%, 스탠퍼드 13%
→ **설명문에만 넣습니다.** 관심 있는 사람은 찾아봅니다.

# 2. 대본 문체 규칙

앞으로 모든 회차에 적용합니다.

1. 한 문장은 한 줄. 25자 넘으면 자른다
2. 파트마다 질문으로 열고, 답으로 닫는다
3. 파트마다 "저는 ~라고 생각합니다"를 최소 한 번
4. 나열은 3~4개 병렬로. "회계사는 회계기준을 알고, 변호사는 법을 알고, 의사는 의학을 압니다"
5. 한 컷에 숫자는 하나만
6. 단정문 뒤에는 반드시 유보를 붙인다. "다만 저도 확신은 못 합니다"
7. 어려운 말은 바로 풀어 쓴다. "미지정" → "수습처를 못 구했다"
