# EP.1 코덱스 대본 — 수령 대기

> **상태: 미수령.** 아래 절차로 채웁니다.

## 절차

1. `codex-order.txt` 전체를 복사해서 코덱스에 붙여넣기
2. 코덱스가 출력한 대본 전문을 이 파일에 그대로 붙여넣기 (**한 글자도 수정하지 말 것**)
3. Claude에게 "대본 왔다" 알리기 → `shotlist.md` 생성

## Claude 수령 시 체크리스트

대본을 받으면 컷 변환 전에 아래를 먼저 검증합니다.

- [ ] 발주서에 없는 통계가 들어갔는가 → 있으면 코덱스 재발주 (Claude가 지우지 않음)
- [ ] 데이터 ⑤(삼정KPMG 신입 375→268 / 전체 1,750→2,095)가 들어갔는가 → **이 영상의 유일한 증명. 없으면 재발주**
- [ ] 반론 3개(㉠㉡㉢)가 다 들어갔는가
- [ ] "저는 ~라고 생각합니다" 계열이 파트마다 최소 1회 있는가
- [ ] 한 문장 25자 초과가 반복되는가
- [ ] `[데이터 필요: ○○]` 표시가 있는가 → 있으면 데이터 정리해서 재발주
- [ ] 회계업계 인명 사고 언급이 있는가 → **있으면 즉시 재발주**
- [ ] 낭독 분량이 3,000~3,300자 범위인가
