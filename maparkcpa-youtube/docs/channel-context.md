## 운영자 커리어 (개인 서사에 사용)

2013년 31세 제48회 CPA 합격 → **실무수습 미지정으로 로컬 회계법인 계약직**
→ 가톨릭대학교병원 재무팀 1년 → 미래회계법인 2년
→ EY한영 (**경력 1년 낮춰 입사**) → 삼정KPMG → 정동회계법인 개업·파트너
현재 연매출 3~4억

> "좋은 직장을 한 번 고르는 것보다, 환경이 바뀔 때 내 위치를 다시 고르는 능력"

## 대본 문체 규칙 (전 회차 공통)

1. 한 문장은 한 줄. 25자 넘으면 자른다
2. 파트마다 질문으로 열고, 답으로 닫는다
3. 파트마다 "저는 ~라고 생각합니다"를 최소 한 번
4. 나열은 3~4개 병렬로 리듬을 만든다
5. 한 문단에 숫자는 하나만
6. 단정문 뒤에는 반드시 유보를 붙인다 — "다만 저도 확신은 못 합니다"
7. 전문용어는 바로 풀어 쓴다 — "미지정" → "수습처를 못 구했다"
8. 톤: 강의가 아니라 **저녁에 후배한테 얘기해주는 톤**
