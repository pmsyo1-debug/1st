# ⚠️ 먼저 확인할 것 3가지

### 1. 메모리는 따라오지 않습니다
claude.ai 세션에 저장한 워크플로우 메모리는 **Claude Code로 전달되지 않습니다.**
프로젝트 루트에 `CLAUDE.md`를 만들고 아래 블록을 넣어주세요.

```md
## 유튜브 대본 작업 워크플로우

- 대본 초안은 항상 코덱스(Codex)가 작성한다. Claude는 대본을 직접 쓰지 않는다.
- Claude의 역할:
  1. 코덱스에게 넘길 **발주서** 작성 — 검증된 데이터·숫자·출처, 구성 방향, 톤 조건을 정리
  2. 코덱스가 쓴 대본을 받아 **영상으로 완성** — 컷 분할, 화면 지시, 모션그래픽 스펙,
     Higgsfield 프롬프트, 제목/썸네일/업로드 메타
- 대본에 정보가 부족하면 Claude가 문장을 고치지 않는다.
  필요한 정보를 정리해서 **코덱스에게 재발주**한다.
```

### 2. Higgsfield MCP를 다시 붙여야 합니다
claude.ai에는 Higgsfield MCP가 연결돼 있었지만 Claude Code는 별도 설정입니다.
`.mcp.json` 또는 `claude mcp add`로 등록하세요. 서버 URL: `https://mcp.higgsfield.ai/mcp`

### 3. 코덱스는 Claude가 호출할 수 없습니다
claude.ai 도구 목록과 커넥터 디렉터리를 모두 확인했으나 코덱스/GPT 호출 도구는 없었습니다.
발주서를 **사람이 직접 코덱스에 붙여넣고**, 결과 대본을 다시 Claude에 주는 흐름입니다.
(Higgsfield 이미지 모델 목록에 "GPT Image 2"가 있어서 혼동이 있었던 것으로 보입니다.
 그건 이미지 생성 모델이지 대본 작성 도구가 아닙니다.)

# 3. 결정 이력 (같은 실수 반복 방지)

### v1 → v2: 제목과 구성을 직장인 중심으로
회계사 데이터로 시작하면 30~50대 직장인이 스크롤합니다.
**회계업계는 주제가 아니라 증거입니다.** "먼저 겪은 업계의 미리보기" 위치로 이동시켰습니다.

### v2 → v3: 대본 톤 실패 (중요)
Claude가 쓴 v2 대본이 "뉴스 보도" 톤이라 반려됨. 원인 4가지:

1. **숫자를 15개 넣음** — 2분 30초에 통계 6개 연속. 하나도 기억 안 남
2. **질문이 없음** — 전부 단정문. 채널 취지인 "같이 고민하자"가 사라짐
3. **"저는 ~라고 생각합니다"가 없음** — 이게 의견 공유와 보도를 가르는 장치
4. **문장이 김** — 눈으로 읽으면 괜찮지만 소리로 들으면 못 따라감

→ 이후 **대본은 코덱스 담당으로 이관.** Claude는 발주서와 영상화만.

### 2026-08-22 세션: 대본 수령 후 결정 3건

1. **경력회사 실명 익명화** — PART 3의 미래회계법인/EY한영/삼정KPMG를 "회계법인 / 대형 회계법인 /
   또 다른 대형 회계법인"으로 처리. 법적 문제는 없으나 대표님 부담 고려.
   단 PART 2의 삼정KPMG(경향신문 공개 데이터)와 정동회계법인(현 소속)은 실명 유지.
   → 커리어 타임라인 그래픽에도 회사명 자막 금지. 로고·CI 사용 금지.
2. **삼일회계법인 삭제** — PART 2 숫자 과밀(70초에 14개, v2 반려 원인의 재발) 해소 겸,
   무관한 법인을 근거 수치 없이 거명하지 않기 위해. 수치는 설명문으로 이동.
3. **러닝타임 초과 수용** — 코덱스 타임코드가 호흡을 계산에 넣지 않아 엔딩이 7.3자/초(낭독 불가).
   실측 기준 11:57. 발주서 목표 10분을 넘기나 본문은 자르지 않음.

### 최종 결정: 데이터는 5개만
발주서에서 통계를 5개로 제한했습니다. 나머지는 영상 설명문으로 밀어냈습니다.

# 5. 영상 제작 규격

## 디자인 시스템

```
배경        #0E1116  (딥 차콜)
본문 텍스트  #F2F3F5  (오프화이트)
보조 텍스트  #8A9099  (그레이)
감소·경고    #C7483B  (딥 레드)
증가·기준    #E8A33D  (앰버)
그리드선     #1E242C
```

- 폰트: Pretendard (대형 숫자 Bold 900 / 본문 Medium 500)
- 숫자 애니메이션: 카운트업 0.8초 + 이징 아웃
- 컷 전환: 하드컷 기본, 파트 전환만 디졸브
- 모션 원칙: 요소는 한 번에 하나씩. 동시 등장 금지
- BGM: 저음 앰비언트 단일 트랙 -22dB. 긴장 조성용 스팅어 금지
- 출처 자막: 데이터 컷 하단 좌측 고정, 12pt, 그레이

## Higgsfield 사용 원칙

- **전체의 25~30%만** 생성 클립. 나머지는 모션그래픽
- 숫자·그래프를 AI 생성 영상으로 만들지 말 것 (신뢰도 하락 + 크레딧 낭비)
- 생성 클립은 **개인 서사 구간 + 분위기 컷**에만

## 주인공 캐릭터 규격

대표님 본인 초상이 아니라 **익명의 대역**입니다. 특정 인물로 식별되지 않게 항상 뒷모습·측면·원거리.

```
30대 초반 한국인 남성 / 짙은 회색 정장, 넥타이 없음, 화이트 셔츠
검은 단정한 머리, 무테 안경 / 표정 절제, 정면 클로즈업 없음
```
